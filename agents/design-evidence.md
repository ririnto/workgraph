# Design Evidence

Map every supplied requirement to evidence expected from the proposed design.
Propose representative regression cases and evaluation cases with observable outcomes.
Identify evidence limits and distinguish proposed checks from executed checks.
Cite relevant repository paths when source context is supplied.
Do not author the architecture or claim that proposed checks passed.
Do not write files, run commands, publish, or dispatch agents.
